
# AuthPortal — Login & Registration UI

A responsive Login and Registration interface built as part of the ApexPlanet Full Stack Web Development Internship (Task 2).

## About the Project

AuthPortal demonstrates a modern authentication interface using HTML5, CSS3, JavaScript, and Bootstrap 5. It includes responsive layouts, interactive forms, client-side validation, and a basic AJAX demonstration.

## Features

- Responsive navigation bar
- Mobile-friendly layout
- Bootstrap 5 carousel
- Dismissible welcome and demo alerts
- Quick Access cards for Login and Register
- Login and Registration modal forms
- Client-side input validation
- Password visibility toggle
- Password confirmation validation
- Loading indicators and submission feedback
- AJAX demo using the JavaScript Fetch API
- Responsive footer

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Fetch API
- JSONPlaceholder test API

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the Login, Register, carousel, and AJAX demo features.

An internet connection is required to load Bootstrap from the CDN and retrieve sample AJAX data.

## Important Note

This is a frontend demonstration project. Login and Registration forms perform client-side validation only. They do not create real accounts, authenticate users, or connect to a database.

The AJAX demo retrieves sample data from JSONPlaceholder and does not submit login credentials.
