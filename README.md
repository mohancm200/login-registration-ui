# Login & Registration UI

A responsive Login and Registration user interface developed as part of **Task 2 of the ApexPlanet Full Stack Web Development Internship**.

## Project Overview

This project focuses on building a modern, responsive frontend interface using Bootstrap 5, HTML, CSS, and JavaScript.

The interface is designed to work across desktop, tablet, and mobile screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Current Features

- Responsive Bootstrap navigation bar
- Responsive hero section
- Bootstrap grid system
- Responsive feature cards
- Login and Registration interface section
- Bootstrap modal
- Responsive buttons
- Bootstrap Icons
- Mobile-friendly layout
- Smooth scrolling
- Custom CSS styling
